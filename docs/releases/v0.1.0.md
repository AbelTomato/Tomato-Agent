# Tomato Agent 0.1.0

Tomato Agent 0.1.0 is the first public Windows x64 desktop release. It provides native chat, local conversation storage, and project-based organization for chat sessions.

## Install

Download `Tomato-Agent-0.1.0-x64-setup.exe` and run it on Windows x64. Configure an OpenAI-compatible model provider in the app before starting a conversation.

The installer is unsigned. Windows SmartScreen may show a source warning. Verify the installer with the published `Tomato-Agent-0.1.0-x64-setup.exe.sha256` file before running it.

## Known limitations

- A clean first install under a separate Windows user account has not been independently verified for this source revision.
- Uninstall data-retention behavior has not been verified. Back up application data before uninstalling.
- This release does not claim real-provider quality acceptance or signed-installer status.
