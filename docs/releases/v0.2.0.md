# Tomato Agent 0.2.0

Tomato Agent 0.2.0 brings the desktop app's chat and agent tasks onto one persistent Runtime, with controlled project access and reviewable file changes.

## What's new

- Use one conversation entry point for assistant runs. Sessions, visible messages, run status, and events are stored by the unified Runtime; existing desktop chat history migrates to it.
- Grant project reading for a run, then review proposed file changes as a diff. Project files are written only after explicit approval in the desktop app.
- Keep project access within the registered project. Changes are checked against the original file content before writing, so external edits are preserved and reported as conflicts.
- Recover pending approvals and file-commit status after page reload or application restart. Failed writes remain visible for inspection.
- Use the bundled Windows engine, which starts when needed and is reused by later Runtime operations.

## Install

Download `Tomato-Agent-0.2.0-x64-setup.exe` and run it on Windows x64. Configure an OpenAI-compatible model provider before starting a conversation.

The installer is unsigned. Windows SmartScreen may show a source warning. Verify the installer with the published `Tomato-Agent-0.2.0-x64-setup.exe.sha256` file before running it.

## Known limitations

- A clean first install under a separate Windows user account has not been independently verified for this release.
- Uninstall data-retention behavior has not been verified. Back up application data before uninstalling.
- The Runtime workflow was verified with a local simulated provider; this release does not claim real-provider quality acceptance or signed-installer status.
