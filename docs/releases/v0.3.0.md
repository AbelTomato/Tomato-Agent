# Tomato Agent 0.3.0

Tomato Agent 0.3.0 adds end-to-end Runtime tracing from Python task execution through the desktop engine to persistent trace logs.

## What's new

- Record structured spans for assistant runs, model calls, tools, memory, and knowledge retrieval, linked by trace and parent IDs.
- Restrict trace records to approved metadata and stable error categories. Request and response bodies, prompts, and raw exception text are not stored.
- Expose authenticated, cursor-based trace reads to the attached desktop engine.
- Consume traces in the Rust desktop host and persist them as UTC-dated JSONL logs with a 30-day retention window.
- Resume consumption after restart, deduplicate replayed records, and record loss markers when the in-memory buffer has overwritten unread spans.

## Install

Download `Tomato-Agent-0.3.0-x64-setup.exe` and run it on Windows x64. Configure an OpenAI-compatible model provider before starting a conversation.

The installer is unsigned. Windows SmartScreen may show a source warning. Verify the installer with the published `Tomato-Agent-0.3.0-x64-setup.exe.sha256` file before running it.

## Known limitations

- Trace spans that have not been consumed may be lost when the Python engine exits; the desktop host records a loss marker when it detects buffer overflow.
- A clean first install under a separate Windows user account has not been independently verified. Uninstall data-retention behavior has not been verified; back up application data before uninstalling.
- This release does not claim real-provider quality acceptance or signed-installer status.
