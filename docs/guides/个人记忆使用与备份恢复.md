# 个人记忆使用与备份恢复

本说明适用于默认 Windows 应用标识 `dev.tomato.agent`。记忆保存在本机，不通过 Tomato Agent 账户进行跨设备同步。

## 启用与管理

在普通聊天窗口打开设置，启用“长期记忆”。记忆默认关闭。启用后，新消息仍发送给当前配置的聊天服务；引擎会将用户消息用于识别可管理的长期事实。明确的“记住/更正”请求会即时处理；其他稳定自述由自动策略处理，存在歧义或冲突时进入待确认列表。

长期记忆管理视图可查看已保存事实、来源摘录和待确认候选。用户可更正、接受、拒绝、忘记单条记忆、清空全部个人记忆或导出 JSON。普通聊天回复下会列出本轮实际使用的事实和来源。离线时，忘记和清空会先在本机停用相关记忆；界面显示待同步状态，同步完成前暂停记忆读取。

关闭设置中的“长期记忆”会停止后续自动提取和记忆注入，但不会删除已经保存的事实。需要删除事实时，在记忆管理中使用“忘记这条记忆”或“清空全部个人记忆”。清空后不可从应用内恢复；恢复旧备份可能重新带回备份时仍存在的事实。

记忆会影响后续回答，因此启用后只保存自己愿意让助手长期使用的信息。来源摘录来自用户消息。记忆事实可能作为提示上下文发送给当前配置的聊天服务。不要将密码、API Key、支付凭据或其他不希望进入模型请求的信息写入聊天。

## 本机位置

Windows 默认数据目录为 `%APPDATA%\dev.tomato.agent\TomatoAgent`：

- `desktop-chat\chat.sqlite3`：普通聊天、项目、记忆开关、来源同步 outbox/tombstone 和已使用记忆的版本引用。
- `engine\agent.db`：助手任务、记忆事实/版本/来源、提取任务、摘要、检索派生数据和删除水位。
- `engine\workspaces`、`engine\artifacts`：助手工作区和生成产物；可按自己的数据保留策略另行处理。
- `drafts`：应用配置的写作草稿目录，当前桌面默认在 `%LOCALAPPDATA%\TomatoAgent\drafts\dev.tomato.agent`。

模型 API Key 由 Windows Credential Manager 管理，不在上述目录，也不包含在文件备份中。更换 Windows 账户或设备后需重新配置 API Key。

## 备份与恢复

备份时先完全退出 Tomato Agent，确认桌面应用及其助手引擎均已关闭，再把 `desktop-chat` 和 `engine` 两个目录复制到安全位置。两者应作为同一时间点的一组数据备份：聊天库包含待同步删除记录和回复的事实版本引用，引擎库包含相应事实、来源与删除水位。只备份其中一个目录会造成历史引用或待同步操作不匹配。

恢复时先完全退出应用，把同一备份中的 `desktop-chat` 和 `engine` 还原到对应数据目录，再启动应用。应用重新连接引擎后会继续处理备份中尚未完成的同步操作。恢复旧备份会回到该备份时间点的记忆状态；它不知道备份之后发生的忘记或清空操作。若恢复后要确保某条事实不再保留，请在记忆管理中再次忘记或清空，并等待同步状态恢复正常。

只想删除本机全部聊天和记忆数据时，先通过记忆管理清空记忆并等待同步完成，再退出应用。随后删除 `%APPDATA%\dev.tomato.agent\TomatoAgent\desktop-chat` 和 `%APPDATA%\dev.tomato.agent\TomatoAgent\engine`。直接删除数据目录会同时移除会话、助手任务、记忆来源和本地撤销水位；卸载应用不代表数据已清除。

隔离验收或使用自定义应用标识构建时，Tauri 会用该标识建立另一数据目录。请以该应用的实际 `%APPDATA%` 子目录为准，勿把隔离验收数据与日常数据混合恢复。
