# Windows 桌面使用说明

Tomato Agent 维护中的产品是 Windows x64 Tauri 桌面应用。安装后不需要 WSL、浏览器或单独安装 Python。普通聊天运行在 Rust 桌面宿主中；助手、知识、写作和受控代码任务需要时启动随包分发的 Python 引擎。

## 首次使用

1. 安装并启动 Tomato Agent。
2. 打开模型设置，填写服务商提供的 OpenAI 兼容 API Base URL、模型名称和 API Key。
3. 显式测试连接，通过后保存设置。
4. 直接开始普通聊天，或在输入区选择“助手”或“写作”模式提交多阶段任务。

API Key 保存在 Windows Credential Manager；端点和模型名称保存在桌面应用数据中。聊天请求不会自动重试。Provider 费用及数据处理遵循所配置服务商的条款。

## 项目与权限

项目用于按本机目录归类会话。创建项目或将会话归类到项目，不会读取该目录，也不会授予文件访问权。仅当助手任务需要工作区时，应用才会请求登记；用户必须明确选择并登记可用目录，任务之后才能使用。

会话移入或移出项目只改变导航分组。删除项目不会删除磁盘目录、消息或会话。目录被移动或删除后，项目仍保留并显示不可用状态，等待用户修复或移除。

## 本地数据

默认应用标识为 `dev.tomato.agent`，数据位于安装目录之外：

- `%APPDATA%\dev.tomato.agent\TomatoAgent\desktop-chat\`：聊天历史、项目分组和桌面偏好。
- `%APPDATA%\dev.tomato.agent\TomatoAgent\engine\`：助手任务数据库和恢复状态。
- `%LOCALAPPDATA%\TomatoAgent\drafts\dev.tomato.agent\`：桌面写作流程保存的草稿。
- Windows Credential Manager：Provider API Key。

长期记忆默认关闭；开启后的记忆范围、来源、管理操作和聊天/引擎数据成对备份恢复方式见[个人记忆使用与备份恢复](个人记忆使用与备份恢复.md)。

备份前先完全退出应用。若要保留任务历史和恢复状态，应同时备份聊天及引擎数据。文件备份不包含 API Key；更换 Windows 账户或设备后需重新填写。

## 网络与任务异常

- 未完成模型配置时，应用会提示用户先配置再发送。
- DNS、代理、防火墙、TLS、Provider 认证和模型错误会显示在桌面界面；重试前检查端点及账户状态。
- 取消或失败的聊天生成不会保存为完整回答。
- 写作保存结果不确定时，任务会保留在可恢复的等待状态；应用未显示保存位置前，不要假设草稿已保存。
- 复杂任务状态由引擎持久化，并在重启后重新核对。外部副作用状态不确定时需要人工核查，不会盲目重放。

## 安装与卸载

安装包为未签名的 Windows x64 NSIS 包，SmartScreen 可能显示来源提示。卸载前备份应用数据。干净用户环境安装和卸载后数据保留尚未宣称通过；不要依赖卸载流程保留或删除用户数据。
