# 系统设计

## Runtime 边界

核心 Agent Runtime 由使用者手动实现。本仓库不实现 LLM 决策和 Loop，仅定义 `LLMClient`、`RunResult`、工具和持久化接口。

## 状态恢复

每个 Run 通过 Event 和 Checkpoint 持久化。恢复时读取最后 checkpoint 和事件序列；Runtime 自行决定是否重试未完成工具调用。

## 工具安全

calculator 使用 AST 白名单；read_docs 使用固定文档根目录和路径穿越校验；search 通过 Provider 抽象接入外部服务，默认使用 Mock Provider。

## Context

Context 按系统指令、Session 摘要、相关记忆、未解决问题、最近消息组织。超限时保留最近消息并生成确定性摘要，不依赖 LLM。
