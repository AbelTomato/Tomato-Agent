- WSL 发现只由设置页用户动作触发；保存设置不连接服务。
- 连接失败不循环重试、不重发任务，错误留在工作区入口并提供设置/重试路径。
- Web 入口与现有 `ConversationShell` 行为保持兼容；Tauri 桌面仍使用原生认证 API bridge。
- 不新增依赖，不自动部署后端，不扩展模型设置。
