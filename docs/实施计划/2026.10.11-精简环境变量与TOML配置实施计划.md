# 精简环境变量与 TOML 配置（计划日期：2026-10-11）

**目标**：`.env` 仅展示 Provider 凭据与连接信息，单个 TOML 管理非敏感策略；旧环境变量继续兼容，不改写现有 `.env`。

**架构**：保持 Settings 平面字段及现有业务接口，新增标准库 tomllib 配置源，按显式参数、进程环境、dotenv、TOML、默认值排序。每个来源内统一新旧 Worker 标识，保证来源优先级。默认文件及存储相对路径锚定 backend。

**技术栈**：Python ≥3.11、Pydantic Settings、tomllib、pytest；不增加依赖。

## 范围与约束

- 主工作树实施，保留已有文件变更、凭据和业务数据，不提交 Git。
- 只使用后端权威 `.env.example`；根目录旧模板改为迁移提示，避免非必要删除。
- 不生成实际 config.local.toml，不变更 RAG 校准、安全边界或业务数据库。
- TOML 拒绝未知项、凭据项和固定安全约束项；固定单并发、禁网及禁止凭据仍由代码校验。
- `Settings(_env_file=None)` 同时禁用默认 TOML；显式 config_file 可用于独立测试。

## 风险与恢复

旧 `.env` 参数优先于 TOML，迁移时必须由用户移走对应旧项才会使用 TOML；默认读取位置固定 backend 是行为变化，文档须明确。缺失默认文件可启动，显式指定文件缺失则失败。代码未改变默认 Worker/RAG 策略；复制示例显式启用 Worker。错误不输出 TOML 值，现有凭据不读取、不打印、不自动迁移。
