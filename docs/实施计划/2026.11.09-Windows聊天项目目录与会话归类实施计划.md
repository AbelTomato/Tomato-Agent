# Windows 聊天项目目录与会话归类实施计划（计划日期：2026-11-09）

## 目标

在现有 Windows chat-only MVP 基础上，增加类似 Codex Projects 的本地项目管理：项目绑定一个 Windows 本地目录，会话可以归入项目；未归类会话仍保留在独立列表。项目目录本阶段只用于项目身份和会话归类，不授予文件读取、工具调用或代码执行权限。

## 已确认范围

- 项目绑定一个本地 Windows 目录；项目名称默认取目录名，用户可以修改。
- 一个会话最多归属于一个项目；项目删除不删除会话和用户目录，会话回到独立列表。
- 未归类会话继续可创建、切换、重命名和删除。
- 支持创建项目、选择已有目录绑定项目、项目重命名、把会话移入/移出项目、按项目浏览会话。
- 不增加“归档/取消归档”状态，不做云同步、目录内容索引、文件访问授权、WSL 连接或代码任务。
- 使用 Windows 原生目录选择器；路径只作为本地元数据保存，不写入 Provider 请求。

## 数据模型

chat-only 专属 SQLite 增加：

- `projects(id, name, root_path, created_at, updated_at)`；`root_path` 唯一且为规范化绝对目录路径。
- `sessions.project_id` 可空，外键指向 `projects.id`，项目删除时置空（不得级联删除会话）。
- 启动时幂等迁移旧 `sessions` 表；现有会话全部保持未归类，旧数据库可重复打开。
- 所有项目和会话操作只访问 `desktop-chat/chat.sqlite3`，不读取后端 `agent.db`、项目数据库或 WSL 偏好。

## 原生与 UI 边界

- Tauri chat-only 入口新增项目 CRUD、会话归类和原生目录选择命令。
- 目录选择使用 `tauri-plugin-dialog`，取消返回空值；路径必须是本地目录，拒绝空路径、控制字符和无法转换的路径。
- 项目删除、会话移入/移出均为显式用户动作；删除项目不删除磁盘目录。
- React 侧栏按“项目 / 独立会话”分组；项目为空时显示空状态；当前会话切换后只读取对应历史。
- 现有普通聊天发送、Provider、凭据和消息数据流保持不变。

## 分阶段任务

### 阶段一：存储与原生命令

1. 增加项目表、会话项目外键和幂等迁移。
2. 实现项目创建、列表、重命名、删除、会话归属和取消归属。
3. 实现原生目录选择命令及路径校验；chat-only 启动注册最小命令集合。
4. 增加 Rust 单元测试：迁移、项目 CRUD、重复目录拒绝、删除项目保留会话、路径校验。

阶段完成标准：`desktop-chat` Rust 测试覆盖所有数据不变量，默认 legacy 测试不受影响。

### 阶段二：桌面项目导航

1. 侧栏展示项目分组和独立会话分组。
2. 新建项目流程：打开目录选择器、填写/确认项目名称、保存后显示项目。
3. 会话菜单提供“移入项目”和“移出项目”，当前会话切换后恢复正确历史。
4. 项目改名、删除确认、目录不可用提示和取消选择状态完整呈现。
5. 使用现有 `lucide-react` 图标和桌面样式，不引入第二套布局。

阶段完成标准：前端行为测试覆盖项目分组、归类、移出、删除确认、空状态、取消选择和迟到请求隔离；chat-mode build 通过。

### 阶段三：兼容与发布验证

1. 旧 chat-only 数据库升级后项目列表为空、旧会话仍可用。
2. 重启应用后项目、项目路径、会话归属和当前会话均恢复。
3. 验证同一目录不能创建两个项目；项目删除不影响磁盘目录和会话。
4. Windows 实机验证本地目录、含空格目录、Unicode 目录、取消选择和不可用目录。
5. 更新 `desktop/README.md` 与 Windows 使用说明，记录数据路径、项目删除语义和备份边界。

阶段完成标准：Rust/前端定向测试、chat-mode 构建、Windows 安装后 UI 验收均有独立证据；真实 Provider 只需复用已有聊天验收，不新增请求场景。

## 不变量与风险

- 项目删除只能解除会话归属，不能删除或移动用户目录。
- 会话最多一个 `project_id`；任何不存在的项目 ID 都被原生层拒绝。
- 路径比较使用规范化绝对路径；不把目录名或路径拼接进 SQL 或 Provider 请求。
- 目录选择是组织能力，不等于文件访问授权；后续若实现来源目录/Agent 文件能力，另立阶段和权限快照设计。
- chat-only 与 legacy 仍保持编译和数据边界隔离；本阶段不合并 WSL 生命周期。
