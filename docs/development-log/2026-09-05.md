## 本轮 Session Repository 关联完整性修复

### 用户 Prompt 原文

### 需求拆解

1. 不允许为不存在的 `session_id` 创建 Run。
2. 不允许为不存在的 `run_id` 插入 Event 或保存 Checkpoint。
3. 不允许使用其他 Session 的 ID 为 Run 插入 Event，避免跨 Session 数据污染。

4. 为所有 SQLite 连接启用 `PRAGMA foreign_keys = ON`，并在新建表结构中声明 Session/Run 外键。
