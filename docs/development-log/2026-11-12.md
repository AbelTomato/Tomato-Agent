# 开发日志 2026-11-12

## 标准化 CI/CD：WSL 调用 Windows PowerShell 构建 Release

- **完成内容**：根据 `docs/local/windows-msvc-path.md` 与本地 Windows 工具记录，从 Ubuntu WSL 调用宿主 Windows PowerShell，完成 Python 引擎、Tauri Windows x64 Release 和 NSIS 安装包构建；安装包归档到 `%LOCALAPPDATA%\TomatoAgent\installers\20261112-002249\`。
- **遇到问题**：PowerShell ExecutionPolicy 拒绝直接执行 WSL UNC 上的 `.ps1`；Windows pip 对 PyPI wheel 下载无进展；uv 从 UNC 项目目录写入默认 Windows cache 时跨驱动器移动失败。
- **解决方式**：将源脚本复制到 Windows `%TEMP%` 并校验 SHA-256 后执行；通过 WSL 下载 PyPI 官方 uv wheel，核对 PyPI SHA-256 后由 Windows Python 3.12 安装；本地打包脚本将 `TEMP`、`TMP` 和 `UV_CACHE_DIR` 固定到 Windows 本地构建目录。修复提交为 `f9e663e`。
- **验证结果**：PowerShell AST 解析错误 `0`；UI production build 成功；锁定环境安装并由 PyInstaller `6.17.0` 构建 Python 引擎成功；Windows x64 Tauri release 与 NSIS 打包成功，安装器大小 `24,596,169` bytes，SHA-256 `AE71E85BF3E97B78972A529C091DD3AFD0DB6CAF1842D17381008D24C01A073B`；manifest 中版本、目标、commit、干净工作树、大小和哈希与实际产物一致；Windows Rust 测试 `33 passed`。
- **限制**：仅构建并校验安装器，没有在独立 Windows 用户或隔离安装目录中执行安装、启动和卸载验收；没有推送 `main`、创建 tag 或发布 GitHub Release。
